Checkbox & Radio Button Guidelines

The same visual and layout rules apply to both checkboxes and radio buttons. Radio buttons must use the RadioGroup component, while checkboxes use the Checkbox component. When you have multiple checkboxes, use the CheckGroup component to organize them with consistent spacing and alignment.

Component Usage

  • RadioGroup: Required for all radio button implementations - handles spacing, orientation, and group behavior automatically.
  • Checkbox: Individual checkbox component for single or multiple checkbox implementations
  • CheckGroup: Used to group multiple Checkbox components with consistent spacing and alignment
