Form Guidelines

Forms are fundamental to content management workflows, from quick filters to complex content creation. Consistent labeling, spacing, and layout ensure forms are both accessible and efficient to complete, especially important given the frequent form usage in our application.

Layout and Spacing

Horizontal Alignment

When multiple form elements appear in the same row, ensure consistent alignment and spacing between elements.

Vertical Spacing

Maintain consistent spacing between form rows to create clear separation and visual rhythm.

Field Organization

Logical Grouping

Group related form fields together and separate different sections with appropriate spacing or visual dividers.

Field Width

Use consistent field widths across most forms. Given that our content often comes from custom vocabularies that vary by customer, uniform field widths create predictable layouts and improve scanability, especially when multiple fields appear in the same row.

Labels & Accessibility

Always Provide Labels

Every form input must have a clear, descriptive label that explains what information is expected.

Label Content

Keep labels short and informative. Long text is difficult to read in label style and creates visual clutter. For fields requiring detailed explanations, use help text, tooltips, or supporting descriptions positioned below the label instead of making the label itself lengthy.

Hidden Labels

When space constraints require hidden labels (such as search fields with icons and placeholders), always include an aria-label for screen reader accessibility.

Label Positioning

Above Labels (Default)

Position labels above form elements for standard forms and multi-field layouts. This creates clear visual hierarchy, accommodates longer labels when necessary, and works well with varying field widths.

Inline Labels (Compact Spaces Only)

Use labels beside the input only when vertical space is severely limited, such as in toolbars, filters, or compact interface elements.

Required vs Optional Fields

Clear Indication

Clearly indicate which fields are required and which are optional using consistent visual markers.

Error Handling and Validation

Visual Error Indicators

Invalid fields must stand out clearly from valid ones using distinct visual styling such as red borders, background colors, or other prominent visual cues.

Error Messages

Display clear, specific error messages directly below the invalid field. Messages should explain what's wrong and how to fix it.

Error Message Placement

Position error messages consistently below the relevant field to create a clear visual connection between the problem and its location.
