Switch guidlines

Similar rules apply to switches as for checkboxes, with the key difference being when to use them. Use switches for settings that take effect immediately without requiring a confirmation button - the switch instantly affects the view or functionality. Use the SwitchGroup component when grouping multiple switches.

Component Usage

  • Switch: Individual switch component for single or multiple switch implementations
  • SwitchGroup: Used to group multiple Switch components with consistent spacing and alignment

When to use Switches vs Checkboxes

  • Switches: For settings that take effect immediately (toggle dark mode, enable notifications)
  • Checkboxes: For selections that require confirmation or submission (form selections, bulk actions)
