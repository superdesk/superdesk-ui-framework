Button Guidelines

Our design system uses three button types to create clear visual hierarchy: Primary for the most important action, Secondary for alternative actions, and Tertiary for low-priority or optional actions. Each type has distinct visual weight to guide users effectively through interfaces.

Primary Buttons

Purpose

Use for the most important action on a page or section. Primary buttons should guide users toward their main goal and stand out clearly from other elements.

Usage rules

Limit to one primary button per view to maintain clear hierarchy. If you think you need two primary buttons, one of them should probably be secondary.

Secondary Buttons

Purpose

Use for important but not critical actions, often paired with primary buttons. They provide alternatives or complementary actions without competing for attention.

Usage rules

Work well alongside primary buttons. Use multiple secondary buttons when you have several actions of similar importance.

Tertiary Buttons

Purpose

Use for low-priority or optional actions. Ideal when you need functionality without visual clutter, especially for buttons that appear frequently in lists or cards.

Usage rules

Great for actions that support the main experience but aren't essential to completing primary tasks.

Mixed Button Types

You can combine different button styles to create a clear action hierarchy.
